
# Veda Technology Website

A responsive technology business website built using HTML5, CSS3 and JavaScript.

## Features

- Responsive navigation
- Homepage and company introduction
- Technology programs
- IT and digital services
- Training and internship information
- Interactive FAQ accordion
- Contact form demo
- SEO meta description and semantic HTML
- Mobile, tablet and desktop support

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension.

## Important

The contact form is a frontend demo only. Connect a backend,
email service or form provider before using it for real enquiries.

Replace sample text with verified company information before
publishing the website.

## Deployment

The static website can be deployed using GitHub Pages, Netlify
